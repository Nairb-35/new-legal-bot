Emotion host faces. Drop PNGs here and the video host swaps mood per line
automatically (mood is picked from each sentence's wording).

Files expected (same character/style/size as ../../kampung_clean.png, white bg):
  sad_closed.png     sad_open.png       (mouth closed / mouth open — for lip-sync)
  serious_closed.png serious_open.png
  angry_closed.png   angry_open.png
  (happy uses the default smiling host — no file needed)

Any missing pair just falls back to the default host, so partial sets are fine.

Easiest way to make them: open Gemini (Google AI Pro), upload kampung_clean.png,
and ask: "Keep this exact character and style, but make him look SAD with his
mouth closed" — then again "...mouth open", and repeat for serious and angry.
